# archivo historico de documentacion

Esta carpeta conserva documentacion tecnica e historica que ya no representa el estado vigente de producto.

## fecha de migracion

- febrero 2026

## criterio

- documentos de roadmap/plan de ejecucion ya cerrados o desactualizados
- reportes de auditoria interna historicos
- material util para trazabilidad, no para lectura de estado actual

## uso recomendado

1. primero leer canonico actual en docs/INDEX.md y docs/product/README.md.
2. usar docs/archive/ solo para contexto historico o trazabilidad.

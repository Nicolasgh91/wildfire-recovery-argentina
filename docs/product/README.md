# documentacion canonica de producto

Esta carpeta concentra la documentacion vigente de Vestigia para producto y experiencia de usuario.

## objetivo

Alinear todo el repo con una narrativa unica:

- exploracion guiada de incendios historicos
- evidencia satelital reproducible para usuarios no tecnicos
- capacidad legal como modulo avanzado, no como historia principal

## documentos canonicos

- `docs/product/backlog-documentacion-2026-02-22.md` (checklist ejecutado de actualizacion documental)
- `docs/product/casos-de-uso-y-estado.md` (fuente unica de casos de uso)
- `docs/product/estado-real-del-producto.md` (semaforo de estado y top 5 de cierre)
- `docs/product/diferenciacion-mercado.md` (investigacion externa y posicionamiento prudente)
- `docs/product/matriz-inconsistencias-2026-02-22.md` (diagnostico claim -> fuente -> accion)

## criterio editorial

- texto principal para publico general, sin jerga innecesaria
- exactitud tecnica validada contra codigo real
- limitaciones documentadas sin sobrepromesas
- historicos movidos a `docs/archive/` con puente desde la ruta original

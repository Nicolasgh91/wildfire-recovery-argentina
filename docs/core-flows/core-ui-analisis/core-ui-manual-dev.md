## Core UI de Análisis y Mapas — Manual para devs/ops

En este manual se documentará:

- Cómo levantar el frontend para probar los flujos de análisis:
  - variables de entorno mínimas,
  - comandos de arranque.
- Cómo navegar y verificar:
  - pantalla de exploración de incendios,
  - mapa principal y capas,
  - filtros y exportaciones.
- Cómo validar la integración con:
  - recurrencia H3,
  - scores de calidad,
  - assets HD generados.

La base será `docs/frontend/README.md` y los componentes listados en `core-ui-overview.md`.
